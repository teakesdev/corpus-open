# Demo matter (synthetic)

A tiny **synthetic** matter for testing matter-kit end to end. Nothing here is a
real case, a real person, or real evidence. Do not use this directory for real
materials.

## Try it

```bash
python3 ../matter.py init .
python3 ../matter.py ingest .
python3 ../matter.py status .
python3 ../matter.py packet . --layer 3min
```
